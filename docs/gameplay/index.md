# Gameplay systems

Features a player sees. Every page states which era the system belongs to:

| Era | Meaning |
| --- | --- |
| Framework-native | Built on the building blocks; rules live in Lua, Forge and YAML |
| Migrated | Started in engine code, moved onto the framework |
| Legacy | Still engine code; documented as it is |

Legacy systems stay documented. They are the comparison that shows what the
framework changed.
