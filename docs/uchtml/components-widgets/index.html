Widget tags

The tags that draw a picture or a control rather than lay out or write text.

img​

AttributeRequirementDefaultConstraints/Notes
pathRequirednonePath to the image resource.
Base AttributesOptionalnoneInherits all common base attributes.
Code Example
<img path="d:/ymir work/ui/example/banner.png" />

button.button​

AttributeRequirementDefaultConstraints/Notes
typeRequired buttonnoneButton type identifier.
targetOptional (either call or target+value must be set)noneThe variable the button will set once clicked.
valueOptional (either call or target+value must be set)noneThe value the button will set to the target variable.
callOptional (either call or target+value must be set)noneThe function to call when the button is pressed. Function must be registered in the Jinja Context
pathRequirednoneImage path template for button states.
tooltip-textOptionalnoneTooltip text.
Base AttributesOptionalnoneInherits all common base attributes.

path is expected to be a parametrized path to the images used for normal, over and clicked state.
UCHTML will then substitute normal hover and selected to the parameter of the string.

Example:

path="d:/ymir work/ui/example/group_b_{}.tga"

become

d:/ymir work/ui/example/group_b_normal.tga
d:/ymir work/ui/example/group_b_hover.tga
d:/ymir work/ui/example/group_b_selected.tga

And each of the images need to exist in order to render the button.

Code Example
<button type="button" path="d:/ymir work/ui/example/group_d_{}.tga" target="bar" value="123" />
<button type="button" path="d:/ymir work/ui/example/group_d_{}.tga" call="interfacemodule.OpenSomething('argument') />

conflict-bar​

AttributeRequirementDefaultConstraints/Notes
leftOptional0Integer value of the left side.
rightOptional0Integer value of the right side.
left-colorOptionalgauge_bpassGauge texture of the left side.
right-colorOptionalgauge_yellowGauge texture of the right side.
tooltip-textOptionalnoneTooltip text. Up to two %d tokens are filled, in order, with the left share and the right share in percent.
Base AttributesOptionalnoneInherits all common base attributes.

A tug-of-war bar between two values. The slider sits in the middle when both are equal and the left side fills left / (left + right) of the bar; with both at zero it sits at 50%. It is not tied to a feature: any two numbers work. Inside a reactive zone it follows the values when they change.

CAUTION

Should not contain any child elements.

Code Example
<conflict-bar width="auto" left="{{ past_score }}" right="{{ future_score }}" left-color="gauge_yellow" right-color="gauge_blue" tooltip-text="Past {{ past_score }} (%d%%) vs Future {{ future_score }} (%d%%)"/>
