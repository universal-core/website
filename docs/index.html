Overview

What is Refine?​

Refine is a React meta-framework for CRUD-heavy web applications. It addresses a wide range of enterprise use cases including internal tools, admin panels, dashboards and B2B apps.

Refine's core hooks and components streamline the development process by offering industry-standard solutions for crucial aspects of a project, including authentication, access control, routing, networking, state management, and i18n.

Refine's headless architecture enables the building of highly customizable applications by decoupling business logic from UI and routing. This allows integration with:

  • Any custom designs or UI frameworks like TailwindCSS, along with built-in support for Ant Design, Material UI, Mantine, and Chakra UI.

  • Various platforms, including Next.js, Remix, React Native, Electron, etc., by a simple routing interface without the need for additional setup steps.

Why Refine?​

Within the broad spectrum of development approaches, Refine occupies a unique sweet spot between “starting from scratch” with traditional development method and low-code/no-code solutions. With their respective initial pros at the beginning of development, both of the two extreme approaches may present long-term risks:

Despite offering the ultimate level flexibility, “Starting from scratch” method is likely to cause

  • Project delays
  • Technical debt
  • Maintenance problems
  • Lack of development and security best practices
  • A polluted codebase
  • And lack of standardization across teams

Low/no-code solutions address this shortcoming but create a new set of challenges such as

  • Vendor lock-in
  • Lack of customization & styling options
  • Poor developer experience
  • And limited support for complex use-cases

Offering the best from both worlds, Refine mitigates all risks of “from scratch” development without compromising from flexibility, agility and open technologies.

Overview of the Refine structure​


1import { Authenticated, type I18nProvider, Refine } from "@refinedev/core";
2import dataProvider from "@refinedev/simple-rest";
3

4import routerProvider, {
5  CatchAllNavigate,
6  NavigateToResource,
7} from "@refinedev/react-router-v6";
8import { BrowserRouter, Outlet, Route, Routes } from "react-router-dom";
9

10import CssBaseline from "@mui/material/CssBaseline";
11import GlobalStyles from "@mui/material/GlobalStyles";
12import {
13  AuthPage,
14  ErrorComponent,
15  RefineSnackbarProvider,
16  ThemedLayoutV2,
17  useNotificationProvider,
18} from "@refinedev/mui";
19

20import { useTranslation } from "react-i18next";
21

22import { authProvider } from "./authProvider";
23import { Header } from "./components/header";
24import { ColorModeContextProvider } from "./contexts/color-mode";
25

26import {
27  CategoryCreate,
28  CategoryEdit,
29  CategoryList,
30  CategoryShow,
31} from "@/pages/categories";
32import {
33  ProductCreate,
34  ProductEdit,
35  ProductList,
36  ProductShow,
37} from "@/pages/products";
38

39function App() {
40  const { t, i18n } = useTranslation();
41

42  const i18nProvider: I18nProvider = {
43    translate: (key, params) => t(key, params).toString(),
44    changeLocale: (lang: string | undefined) => i18n.changeLanguage(lang),
45    getLocale: () => i18n.language,
46  };
47

48  return (
49    <BrowserRouter>
50      <ColorModeContextProvider>
51        <CssBaseline />
52        <GlobalStyles styles={{ html: { WebkitFontSmoothing: "auto" } }} />
53        <RefineSnackbarProvider>
54          <Refine
55            dataProvider={dataProvider("https://api.fake-rest.refine.dev")}
56            notificationProvider={useNotificationProvider}
57            routerProvider={routerProvider}
58            authProvider={authProvider}
59            i18nProvider={i18nProvider}
60            resources={[
61              {
62                name: "products",
63                list: "/products",
64                create: "/products/new",
65                edit: "/products/:id/edit",
66                show: "/products/:id",
67              },
68              {
69                name: "categories",
70                list: "/categories",
71                create: "/categories/new",
72                edit: "/categories/:id/edit",
73                show: "/categories/:id",
74                meta: {
75                  canDelete: true,
76                },
77              },
78            ]}
79          >
80            <Routes>
81              <Route
82                element={
83                  <Authenticated
84                    key="authenticated-inner"
85                    fallback={<CatchAllNavigate to="/login" />}
86                  >
87                    <ThemedLayoutV2 Header={() => <Header sticky />}>
88                      <Outlet />
89                    </ThemedLayoutV2>
90                  </Authenticated>
91                }
92              >
93                <Route
94                  index
95                  element={<NavigateToResource resource="products" />}
96                />
97                <Route path="/products">
98                  <Route index element={<ProductList />} />
99                  <Route path="new" element={<ProductCreate />} />
100                  <Route path=":id" element={<ProductShow />} />
101                  <Route path=":id/edit" element={<ProductEdit />} />
102                </Route>
103                <Route path="/categories">
104                  <Route index element={<CategoryList />} />
105                  <Route path="new" element={<CategoryCreate />} />
106                  <Route path=":id" element={<CategoryShow />} />
107                  <Route path=":id/edit" element={<CategoryEdit />} />
108                </Route>
109                <Route path="*" element={<ErrorComponent />} />
110              </Route>
111              <Route
112                element={
113                  <Authenticated
114                    key="authenticated-outer"
115                    fallback={<Outlet />}
116                  >
117                    <NavigateToResource />
118                  </Authenticated>
119                }
120              >
121                <Route
122                  path="/login"
123                  element={
124                    <AuthPage
125                      type="login"
126                      formProps={{
127                        defaultValues: {
128                          email: "demo@refine.dev",
129                          password: "demodemo",
130                        },
131                      }}
132                    />
133                  }
134                />
135                <Route
136                  path="/register"
137                  element={<AuthPage type="register" />}
138                />
139                <Route
140                  path="/forgot-password"
141                  element={<AuthPage type="forgotPassword" />}
142                />
143                <Route
144                  path="/update-password"
145                  element={<AuthPage type="updatePassword" />}
146                />
147              </Route>
148            </Routes>
149          </Refine>
150        </RefineSnackbarProvider>
151      </ColorModeContextProvider>
152    </BrowserRouter>
153  );
154}
155

156export default App;

Key Features​

  • Refine Devtools - dive deeper into your app and provide useful insights
  • Connectors for 15+ backend services including REST API, GraphQL, NestJs CRUD, Airtable, Strapi, Strapi v4, Supabase, Hasura, Appwrite, Firebase, Nestjs-Query and Directus.
  • SSR support with Next.js & Remix and Advanced routing with any router library of your choice
  • Auto-generation of CRUD UIs based on your API data structure
  • Perfect state management & mutations with React Query
  • Providers for seamless authentication and access control flows
  • Out-of-the-box support for live / real-time applications
  • Easy audit logs & document versioning
