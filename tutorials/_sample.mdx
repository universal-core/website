## A shared greeting

The quest on the right greets the player with a fixed line. Move the text into
a small Lua module so other quests can reuse it.

<CreateFile path="quest/lib/greet.lua" code={greet} />

## Use it from the quest

Call the module from the login trigger. The changed lines are marked in the
editor.

<UpdateFile path="quest/hello.quest" code={helloFinal} />

## The config

The command that repeats the greeting lives in the YAML config.

<ShowFile path="config/hello.yml" lines="3-4" />

Edit any file on the right; **Reset** brings back the state of the last step,
**Solve** shows the finished files.
